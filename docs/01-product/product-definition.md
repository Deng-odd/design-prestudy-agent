# 产品定义

## 一句话定位

面向城市设计项目初期阶段的研究辅助 Agent，通过分析项目条件、检索参考案例、提炼设计机会，辅助规划师形成概念方向建议，并生成前期研究报告。

## 产品定位

城市设计项目启动阶段通常需要完成项目理解、场地分析、案例研究和概念方向探索。该过程高度依赖设计人员经验，存在信息搜集耗时、案例参考分散、研究过程难以复用等问题。

本 Agent 将城市设计前期研究过程转化为结构化工作流程，通过大模型理解项目条件，调用案例检索和图像生成能力，辅助设计人员快速完成从场地分析到概念方向形成的研究过程。

## 目标用户

| 用户类型 | 使用场景 | 核心诉求 |
|---|---|---|
| 规划师 | 项目启动阶段，开展前期研究和概念策划 | 快速完成资料分析、案例研究和方向整理 |
| 项目负责人 | 需要快速判断项目方向，向甲方汇报 | 快速得到可讨论的概念方向 |

## 核心问题

| 问题 | 现状 | Agent价值 |
|---|---|---|
| 信息搜集耗时 | 需要人工整理项目资料、搜索相关案例 | 快速形成研究初稿，减少重复信息整理工作 |
| 案例参考依赖个人经验 | 案例来源和分析深度依赖设计人员积累 | 根据项目条件辅助检索和分析相关案例 |
| 方向提炼缺少结构化方法 | 设计机会识别依赖个人经验 | 基于场地条件和案例信息辅助形成设计方向 |
| 研究报告整理重复劳动 | 需要手动汇总分析内容 | 自动组织研究过程和输出报告 |

## 输入

| 类型 | 形式 | 示例 |
|---|---|---|
| 项目资料 | 文字 | 项目区位、功能定位、发展目标、规划条件 |
| 场地图像 | 图片 | 区位地图、卫星影像、现状照片、规划分析图 |
| 设计目标 | 文字（可选） | 希望重点关注的问题或发展方向 |
| 指定案例 | 文字（可选） | 用户指定参考项目 |

## 输出

| 类型 | 形式 |
|---|---|
| 前期研究报告初稿 | Markdown |
| 场地条件分析 | 结构化文本 |
| 案例研究结果 | 案例信息、空间策略分析 |
| 设计机会与目标愿景 | 文字描述 |
| 概念方向建议 | 2-3个方向 |
| 概念空间意向图 | AI生成图片 |

## 核心能力

### 项目理解与场地分析

理解项目定位、空间资源、城市关系和场地条件，形成结构化分析结果。

### 案例研究

根据项目特征判断参考需求，检索并分析相关案例，提取可借鉴的空间策略。

### 设计机会识别

结合场地条件和案例研究结果，提炼设计机会、发展目标和概念方向依据。

### 概念方向生成

基于前期研究结果生成多个概念方向建议，由设计人员进行选择和调整。

### 报告生成

整理分析过程和生成结果，形成前期研究报告初稿。

## Agent 能力

| 能力 | 体现 |
|---|---|
| 判断是否需要补充研究 | 信息不足时主动追问，不强行生成 |
| 选择研究动作 | 根据项目特征决定检索方向和案例类型 |
| 管理状态 | State 贯穿全流程，所有节点共享上下文 |
| 有限循环 | 案例不够时换关键词再搜，最多 2 轮 |

## 成功标准

| 指标 | 评价方式 |
|---|---|
| 流程完成度 | 能够完成从项目输入到研究报告输出的完整流程 |
| 分析完整性 | 覆盖项目理解、场地分析、案例研究等关键环节 |
| 案例相关性 | 案例与项目类型、资源条件和设计问题具有相关性 |
| 方向有效性 | 概念方向具有差异性，并具备设计逻辑 |
| 结果可靠性 | 案例信息和事实内容具有来源依据 |

## 产品范围

### V1版本支持

- 项目资料理解
- 场地条件分析
- 案例检索与分析
- 设计机会提炼
- 概念方向生成
- 概念空间意向图生成
- 前期研究报告生成

### V1版本暂不支持

- 自动生成详细城市设计方案
- 自动完成空间布局和总平面设计
- 替代设计人员进行最终方案决策
- 专业规划审批判断
