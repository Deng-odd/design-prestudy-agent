# 任务边界

## 任务定位

项目前期研究 Agent 面向城市设计项目启动阶段，辅助设计人员完成信息分析、案例研究和概念方向探索。

Agent 的核心定位是：

将依赖设计人员经验完成的前期研究过程转化为结构化、可复用的智能工作流程，为设计决策提供参考。

Agent 不替代设计人员进行最终设计判断，而是辅助完成研究和方向探索。

## 输入边界

| 输入 | 接受 | 不接受 |
|---|---|---|
| 项目资料 | 文字，100-2000 字 | 语音、视频 |
| 场地图像 | JPG/PNG，区位图/卫星图/现状照片/规划分析图 | CAD、GIS 文件 |
| 设计目标 | 文字（可选） | — |
| 指定案例 | 文字（可选） | — |

## 输出边界

| 输出 | 形式 | 不输出 |
|---|---|---|
| 研究报告 | Markdown | HTML、PPT、PDF、DOCX |
| 概念方向 | 文字描述 | 施工图、效果图 |
| 意向图 | AI 生成图片 | 精确场地还原图 |


# Agent 负责范围

## 1. 项目理解

Agent 负责：

- 理解项目背景和基本条件；
- 提取项目定位、功能类型和核心目标；
- 识别影响设计方向的关键因素。

输出：

- 项目定位分析；
- 核心设计关注点。

## 2. 场地条件分析

Agent 负责：

- 分析区位关系；
- 识别自然资源条件；
- 分析蓝绿空间、公共空间和城市界面；
- 总结场地优势、限制和潜在机会。

输出：

- 场地条件分析；
- SWOT 分析结果。

## 3. 案例研究

Agent 负责：

- 判断是否需要开展案例研究；
- 根据项目特点确定案例研究方向；
- 搜索相关案例；
- 分析案例的空间策略和可借鉴经验。

输出：

- 案例列表；
- 案例分析；
- 参考策略。

## 4. 设计机会识别

Agent 负责：

- 综合场地条件和案例研究结果；
- 提炼潜在设计机会；
- 形成目标愿景。

输出：

- 设计机会点；
- 概念目标。

## 5. 概念方向生成

Agent 负责：

- 基于研究结果生成多个概念方向；
- 描述方向定位、核心策略和空间表达。

输出：

- 2-3 个概念方向建议；
- 概念空间意向图。

设计人员负责：

- 判断方向合理性；
- 选择和调整最终方向。

## 6. 研究报告生成

Agent 负责：

- 整理项目分析过程；
- 汇总案例研究内容；
- 组织设计机会和概念方向；
- 生成前期研究报告初稿。


# Agent 不负责范围

## 1. 不替代专业设计决策

Agent 不负责：

- 确定最终设计方案；
- 判断唯一正确的发展方向；
- 替代设计人员进行方案推敲。

## 2. 不进行详细设计生产

Agent 不负责：

- 自动生成详细总平面方案；
- 建筑单体设计；
- 工程设计；
- 施工图设计。

## 3. 不进行专业审批判断

Agent 不负责：

- 规划审批判断；
- 政策合规最终判断；
- 技术规范审查。

## 4. 不进行专业数据接入

Agent 不负责：

- 接入 GIS 系统；
- 调用真实地图 API；
- 处理 CAD、GIS 文件。


# Agent 自主决策范围

## Agent 可以自主判断

| 判断内容 | 对应节点 |
|---|---|
| 是否需要补充项目信息 | parse_and_check |
| 是否需要开展案例研究 | check_case_need |
| 需要参考哪类案例 | check_case_need 确定研究方向，case_research 生成检索词 |
| 当前案例信息是否足够 | check_research |
| 是否可以进入概念方向生成阶段 | check_research |

## Agent 需要用户参与

| 参与内容 | 触发时机 |
|---|---|
| 调整研究重点 | 任务初始输入或重新发起任务时提供 |
| 指定参考案例 | 任务初始输入或重新发起任务时提供 |
| 选择概念方向 | 报告输出后，由设计人员判断 |
| 修改最终设计目标 | 用户修改后重新发起任务 |

V1 不在运行过程中暂停等待研究方向人工确认或修改，也不增加对应 Graph Node。


# 核心边界总结

| 内容 | Agent 角色 | 对应 Skill |
|---|---|---|
| 信息整理 | 自动完成 | Site Analysis |
| 条件分析 | 辅助完成 | Site Analysis |
| 案例研究 | 自动辅助完成 | Case Research |
| 机会识别 | 提供建议 | Concept Generation |
| 概念方向 | 生成备选方案 | Concept Generation |
| 最终设计决策 | 由设计人员完成 | — |
